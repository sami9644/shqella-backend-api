# Shqella Backend API

A robust Node.js backend application featuring integrated payment processing, database management, and view template rendering.

## 🚀 Tech Stack

* **Runtime:** [Node.js](https://nodejs.org/)
* **Languages:** JavaScript, EJS, HTML, Python
* **Key Files:** 
  * `index.js`: Main entry point for the application.
  * `payment.js`: Handles payment integration logic.
  * `database.js`: Manages database connections and configurations.
  * `views/`: Directory for template rendering.

## 📦 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/sami9644/shqella-backend-api.git](https://github.com/sami9644/shqella-backend-api.git)
   cd shqella-backend-api

```

2. Install dependencies:
```bash
npm install

```


3. Configure your environment variables:
* Set up your `.env` file with the required configuration parameters (such as database credentials and payment gateway keys).



### Running the Application

Start the server:

```bash
npm start

```
